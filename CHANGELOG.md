# Changelog

## 0.5.0

- Add a deterministic four-tool Personal Agent MCP harness and private Git execution with durable receipts.
- Guide users through naming, dedicated plugin setup and host Personalization after first value. Preserve v1 checkpoints.
- Add independent Journal Plan and Actual workflows, multi-intent batches, task lifecycle, and per-target synchronization verification.
- Keep experimental administration allocation opt-in and retain the existing chat and integration routes.

## 0.4.0

- Added optional Star invitations at onboarding milestones and suppress repeated invitations after explicit feedback. Eligible Agents can use a read-only evaluator.
- Preserved compatibility with existing onboarding checkpoints. Star feedback uses an optional private sidecar outside calendar sync triggers.
- Clarified upgrade and rollback protection for workspaces with Plan/Actual and Daily Review.

## 0.3.0

- Added a declarative onboarding workflow, user-input checkpoints, a standalone launch fallback and state recovery across authorized private workspaces.
- Deliver one real result before storage and integrations. Record user decisions, configuration failures and deferrals separately.
- Existing installations adopt daily use without restarting onboarding. The framework upgrade preserves private checkpoints.
- Added conversation fixtures, platform verification matrix and architecture notes. No onboarding runtime is required.

## 0.2.0

- Added link-only launch with task-first onboarding, language selection and GitHub Raw reference resolution.
- Added a lightweight version endpoint and private update settings for new and existing workspaces.
- Added an authorized, conflict-aware upgrade and rollback protocol. Existing task and planning formats are unchanged.

## 0.1.0

The initial kit identified as v0.1.0 in commit `fc12e2c` included private workspace initialization, planning protocols, 12 decision methods and optional calendar and reminder sync.
