# Goal Substitution

Status: enabled

## When to use

An existing path is blocked, redundant or expensive.

## Inputs and reasoning

Identify the intended result, required deliverables and commitments. Compare merging, replacing, splitting, deferring or omitting steps. Check each path for resource fit and goal coverage. Preserve explicit commitments and separately authorize any change to recorded tasks.

## Output

A recommended path with covered goals, remaining obligations and fallback trigger.

## Suggested combinations

Task Compatibility, Constraint-based Planning.
