# Critical Path / Dependency Analysis

Status: enabled

## When to use

Success depends on predecessors or external replies.

## Inputs and reasoning

Map true predecessors, time ranges and waiting periods to the goal. Identify the chain that governs earliest completion and the actions that unlock downstream work. Identify independent preparation. Recheck shared resources and treat uncertain chains as provisional.

## Output

Blocking chain, immediate unlock, parallel candidates and review conditions.

## Suggested combinations

Constraint-based Planning, Value of Information.
