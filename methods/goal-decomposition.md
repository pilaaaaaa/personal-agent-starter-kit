# Goal Decomposition

Status: enabled

## When to use

A goal is abstract, stalled or lacks a next step.

## Inputs and reasoning

Define success, current gap and bottleneck. Consider an issue tree, MECE grouping, root cause, opportunity costs, resource trade-offs or scenarios where they clarify the issue. Identify independent subgoals and a low-friction action that yields observable feedback. Keep inferred goals provisional and ask before persisting a batch of subgoals.

## Output

Goal tree, bottleneck, actionable next step, verification criterion and feedback point.

## Suggested combinations

Goal Substitution, Critical Path, Value of Information, Workflow Optimization, Decision Delegation.
