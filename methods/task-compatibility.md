# Task Compatibility

Status: enabled

## When to use

Potential parallel work, batching or shared trips.

## Inputs and reasoning

Compare visual, auditory, language, cognitive, physical, temporal and spatial demands by task phase. Account for equipment, safety, quality and switching. Identify which task takes priority and what can pause. Preserve rest when it offers greater value.

## Output

Separate, parallel or batched work with a clear stop signal for parallel execution.

## Suggested combinations

Goal Substitution, Multi-objective Optimization.
