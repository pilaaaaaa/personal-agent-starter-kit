# Preference Learning

Status: enabled

## When to use

User feedback could improve future plans.

## Inputs and reasoning

Separate explicit lasting rules, contextual constraints, one-time instructions, observed decisions and inferred patterns. Use dated evidence, feedback and counterexamples. A single acceptance is evidence about the current choice. Record outcomes only when observed. Test contextual explanations before generalizing.

## Output

Scoped updates to the relevant knowledge file and a review trigger for tentative inferences.

## Suggested combinations

Constraint-based Planning, Receding Horizon Planning.
