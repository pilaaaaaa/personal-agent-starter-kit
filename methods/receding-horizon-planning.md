# Receding Horizon Planning

Status: enabled

## When to use

Progress, context or external replies can change.

## Inputs and reasoning

Detail the next actionable interval, protect commitments and long-lead preparation, and keep later slots flexible. Set triggers and replan affected work when they fire. Batch low-impact changes when churn would cost more.

## Output

Near-term plan, future slack, triggers and affected commitments.

## Suggested combinations

Value of Information, Constraint-based Planning.
