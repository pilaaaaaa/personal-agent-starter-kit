# Value of Information

Status: enabled

## When to use

An unknown could change the decision.

## Inputs and reasoning

Name the choice each possible answer would change and compare the loss avoided with query, waiting, rework and interruption costs. Use authorized sources first. For high-impact irreversible choices, verify commitment-changing evidence. For low-impact irreversible choices, verify the minimum necessary details. For high-impact reversible choices, try a recoverable step. For low-impact reversible choices, use a reasonable default.

## Output

What to verify, how long to wait and what can proceed in parallel.

## Suggested combinations

Cost of Delay, Decision Delegation, Receding Horizon Planning.
