# Daily review

Use this method when the user asks to review a day, week or other local date range. Read the journal with the user's time zone. Check elapsed time and compare the Initial Plan, the Rolling Plan and the actual activity timeline. Trace decisions through the versions that were effective when each activity occurred.

1. Identify material changes and their recorded triggers, constraints and effects. Use the preserved versions to distinguish plan changes from later factual corrections.
2. Summarize accomplished work, delays and unexpected activities. Treat exact times, estimates and unknown durations according to their recorded precision. Use total union coverage when activities overlap. Category totals can overlap.
3. Ground any proposed rule in the evidence, specify its scope and when to revisit it, and keep tentative observations as candidates. Ask before recording a lasting preference as confirmed.
4. Apply the relevant changes to the next plan through a new version. Keep historical versions and review evidence intact. Store a review or feedback only within the user's grant.

See the [calendar and journal protocol](../docs/calendars.md) for commands and data fields.
